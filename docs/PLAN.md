# Phase 1 Plan: Re-writing-History (Motion Elevation)

## 1. Library Selection & Strategy
* **Strategy**: Pure CSS `@keyframes` + Vanilla JS IntersectionObserver.
* **Justification**: Zero JS bundle overhead for Go server-rendered HTML UI.

## 2. Targeted Interactions
* **Commit Timeline**: Staggered card entrance reveal.
* **SHA Pills**: Scale and subtle glow on hover.
* **Engine Pulse**: Live status indicator light pulse.
* **Accessibility**: Respect `prefers-reduced-motion: reduce`.
